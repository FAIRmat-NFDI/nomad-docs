# How to create a NOMAD Central account and sign in

Exploring public data stored at NOMAD Central can be done without signing in. However, managing your own data, e.g., uploading, sharing, publishing, requires an account.

These instructions apply to NOMAD Central.
Authentication on a NOMAD Oasis can differ; ask the Oasis administrator which
sign-in method to use.

<a id="create-a-nomad-account"></a>
<a id="sign-in-via-helmholtz-aai"></a>

## Sign in or create an account

1. Open [NOMAD Central](https://nomad-lab.eu/prod/v1/gui/v2/){:target="_blank" rel="noopener"}
   and select the **sign-in icon** (an arrow pointing into a door) in the
   upper-right corner.
2. On the sign-in page, choose one of these methods:

    - **NOMAD account:** Sign in with your NOMAD credentials, or create a new account by selecting **Register**. Complete the form and security
      check, and select **Register** again. Follow the link in the verification
      email to activate the account before signing in.
    - **External accounts:** To sign in using an account from a participating institution or
      another available identity provider, select **University / Institute /
      ORCID / Other**. This will take you to the Helmholtz ID page. Search for and select your provider, then follow its
      instructions to complete sign-in. See the
      [Helmholtz AAI](https://hifis.net/aai/){:target="_blank" rel="noopener"}
      website for more information.
