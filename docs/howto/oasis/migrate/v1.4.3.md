# Migrate to NOMAD 1.4.3

## NORTH Migration

If your Oasis uses NORTH, update its configuration before starting the upgraded stack. The updated distribution runs NORTH in a separate image and reads its secrets and authentication settings from `.env.north` in the distribution directory.

1. **Back up your existing `.env`, `.env.north` (if present), and NORTH configuration.** Keep your existing NORTH data volume.

2. **Create or update `.env.north`** using the updated distribution's `scripts/generate-env.sh` as a reference.

    You can generate the environment files with:

    ```bash
    bash scripts/generate-env.sh
    ```

    **The script overwrites both `.env` and `.env.north` after confirmation**, generating new secrets and default Keycloak settings. If you use it, restore your existing API secret, matching hub service API token, JupyterHub encryption key, and any installation-specific settings from the backups before continuing. Updating `.env.north` manually avoids replacing unrelated secrets.

3. Once your Oasis is running, verify that you can sign in to NORTH and launch a tool from the Oasis UI.
